# 🧮 外贸智算台 · TradeCalc Workbench

**报价 · 物流 · 利润核算 · 汇率 · 报价单** —— 面向外贸业务员与跨境电商卖家的本地优先工作台。

> 零第三方依赖 · 开盒即用 · 数据全部保存在本机，不上传任何服务器

---

## 一、解决的痛点

外贸与跨境电商从业者在报价和利润核算上长期依赖 Excel 手工计算：

| 痛点 | 传统做法 | 本产品 |
| --- | --- | --- |
| 体积重/计费重算不清 | 计算器手算长宽高÷除数，再与实重取大 | 自动计算并多承运商比价 |
| 汇率天天变，报价容易亏 | 手工查汇率、心算换算，亏了才知道 | 实时汇率自动抓取 + 离线缓存 + 手动覆盖 |
| 隐性成本漏算 | 只算采购价，漏关税/平台佣金/收款费/广告费/汇损 | 全链路成本模型，逐项列明 |
| 利润率靠拍脑袋 | 估算售价，账期后才发现亏本 | 目标利润率一键反推建议售价，含保本价 |
| 汇率波动吞噬利润 | 无法量化风险 | 汇率敏感性分析：±1%/2%/5% 对利润的影响 |
| 报价单制作慢且不规范 | Word/Excel 手排，双语翻译费时 | 中英双语报价单一键生成，打印即 PDF |

## 二、快速开始（开盒即用）

**方式一：启动本地服务（推荐，汇率代理更稳）**

```bash
npm start
# 浏览器打开 http://localhost:8080
```

**方式二：零安装直接打开**

双击打开 `public/index.html` 即可（此时汇率需联网自动获取，或手动输入；断网时使用本地缓存/手动汇率）。

> 无需 `npm install`，没有任何第三方依赖。

## 三、功能模块

1. **📊 报价与利润核算**
   - 固定成本：采购 / 包装 / 国内费用 / 物流 / 其他
   - 关税：自动计税基数（=固定成本折算价）或手动指定
   - 变动费率：平台佣金 / 收款费率 / 广告费率 / 汇损缓冲 / 其他
   - 目标利润率 → 自动反推 **建议售价**，并给出 **保本价**
   - 指定售价 → 正向核算单件利润 / 利润率 / 盈亏状态
   - **汇率敏感性分析**：人民币 ±1%/±2%/±5% 对利润的影响条形图

2. **🚚 物流运费计算**
   - 实重 / 长宽高 → 自动算体积重、计费重（除数 6000/5000/8000 可选）
   - 多承运商自定义费率（基础费 + 每公斤 + 操作费 + 燃油附加费 + 最低消费）
   - 一键比价（按总费用升序，标记最省），体积重大于实重自动预警
   - 一键把最低承运商费用填入核算模块

3. **💱 汇率中心**
   - 自动抓取 open.er-api.com / frankfurter.app（欧洲央行）实时汇率
   - 支持 30+ 常用币种，可手动覆盖（标记「手动」，刷新后可保留）
   - 结果缓存于本地，断网可用缓存 + 手动值

4. **📄 报价单生成**
   - 卖方/买方公司信息、交易条款（FOB/CIF/EXW 等）
   - 报价明细多行，首行自动联动核算价
   - 报价单号自动生成，中英双语排版，浏览器打印导出 PDF

5. **⚙️ 数据管理**
   - 全部数据本地自动保存（localStorage）
   - 导出 / 导入 JSON 备份，一键清空
   - 「载入示例」一键体验完整流程

## 五、技术说明

- 纯原生 JavaScript + CSS + HTML，无框架、无构建、无第三方运行时依赖
- 计算引擎 `public/core.js` 为纯函数，浏览器与 Node 双端复用（UMD）
- 静态服务器 `server.js` 同时充当汇率代理（`/api/fx`，多源 failover + 15 分钟缓存），解决浏览器 CORS 与内网场景
- 数据隐私：所有业务数据仅存于本机浏览器与本地 JSON 备份

## 六、注意事项

- 承运商费率为参考模板，请按实际货代报价调整
- 汇率仅作报价参考，实际成交以银行 / 收款平台为准
- 关税税率因目的国 / HS 编码而异，请以海关实缴为准
