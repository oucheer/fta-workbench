关于

外贸智算台 TradeCalc Workbench v1.0 — 为外贸业务员与跨境电商卖家打造的本地报价·利润核算工具。

已解决痛点：手动算体积重 / 查汇率 / 套公式 / 漏算关税与平台费 / 报价单制作耗时易错。

运行方式：npm start 后浏览器打开 http://localhost:8080；也可直接双击打开 index.html（此时汇率需联网或手动输入）。
